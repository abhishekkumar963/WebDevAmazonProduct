# 🛒 Amazon Clone Website

Welcome to the **Amazon Clone** project — a visually stunning and fully responsive frontend replica of the Amazon website. This project is built using pure **HTML** and **CSS**, designed to reflect the real-world structure and appearance of Amazon’s homepage.

## ✨ Features

- 💻 **Responsive Design**: Works seamlessly across desktops, tablets, and mobile devices.
- 🧩 **Reusable Components**: Header, navigation bar, product cards, and footer elements are reusable and modular.
- 🔍 **Search Bar UI**: Styled search bar with dropdown category menu and search icon.
- 🛒 **Shopping Cart Icon**: Amazon-style cart interface with placeholder item count.
- 📦 **Product Listings**: Visually styled product boxes, images, and descriptions.
- 🌙 **Custom Styling**: CSS-based hover effects, button styles, and layout techniques.
- 🏷️ **Amazon-Like Categories**: Displays various sections like electronics, books, fashion, and more.

---



## 🛠️ Technologies Used

- **HTML5** – Markup for content structure  
- **CSS3** – Styling, layout, flexbox/grid responsiveness  
- *(No JavaScript or frameworks used — pure frontend UI)*
